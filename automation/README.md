# Автоматизированное тестирование на Java

Три учебных проекта, покрывающих разные уровни тестирования: юнит, API, UI. Все проекты на Java, собираются через Maven.

## 1. Юнит-тестирование — [Diplom_1](https://github.com/Ilyati7/Diplom_1)
- Покрытие бизнес-логики класса `Burger` юнит-тестами.
- **Стек:** Java, JUnit 4, Mockito, JaCoCo.
- **Результат:** 100% покрытие по JaCoCo, 39 тестовых методов.
- **Навыки:** изоляция зависимостей через моки, параметризованные тесты, анализ покрытия.

## 2. API-тестирование — [Diplom_2](https://github.com/Ilyati7/Diplom_2)
- Автоматизация тестирования API сервиса Stellar Burgers.
- Покрыто: регистрация, авторизация, создание заказа (с ингредиентами, без ингредиентов, с невалидными данными, без авторизации).
- **Стек:** Java, REST Assured, JUnit 4, Allure, Lombok, DataFaker.
- **Навыки:** работа с HTTP-запросами, проверка статус-кодов и тела ответа, генерация уникальных тестовых данных, отчёты Allure.

## 3. UI-тестирование — [Diplom_3](https://github.com/Ilyati7/Diplom_3)
- Автоматизация UI-тестов Stellar Burgers с паттерном Page Object.
- Покрыто: регистрация, логин, работа с конструктором бургеров, переходы между разделами.
- **Стек:** Java, Selenium WebDriver, JUnit 4, Allure, Page Object, Lombok, JavaFaker.
- **Навыки:** поиск локаторов, явные ожидания, кросс-браузерное тестирование (Chrome, Яндекс.Браузер), генерация отчётов Allure.

## Итог
3 проекта → 3 уровня тестирования. Все собираются через `mvn clean test`, имеют отчёты (JaCoCo / Allure) и инструкции по запуску в README.
