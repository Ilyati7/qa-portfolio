# Ручное тестирование: учебный тренажёр «Яндекс.Самокат» (дипломная работа)

**Цель:** пройти полный цикл ручного тестирования веб-приложения для заказа самокатов — от анализа требований до баг-репортов.

## Что было сделано
- Составлен **чек-лист на 69 проверок** для экрана «Статус заказа»: базовая функциональность, отображение данных, статусы, логика отмены, просроченный заказ.
- Проанализированы требования и выделен **121 класс данных** для валидации полей ввода (эквивалентные классы и граничные значения).
- Написано **24 тест-кейса** для тестирования пуш-уведомлений в мобильном приложении курьера.
- Обнаружено и задокументировано **58 баг-репортов** с приоритетами, шагами воспроизведения, ожидаемым и фактическим результатом, окружением.
- Дополнительно проверена логика отмены заказа через **API** с помощью Postman.

## Структура
- [`checklist/`](./checklist/) — чек-лист экрана «Статус заказа» (69 проверок).
- [`test-cases/`](./test-cases/) — тест-кейсы пуш-уведомлений мобильного приложения (24 шт.).
- [`bug-reports/`](./bug-reports/) — список найденных дефектов (58 шт.).
- [`bug-reports/bugs-outside-test-documentation.md`](./bug-reports/bugs-outside-test-documentation.md) — баги, найденные вне тестовой документации (25 шт.).
- [`data-validation/`](./data-validation/) — таблица классов валидации (121 класс).

## Инструменты
DevTools, Postman, ручное тестирование в Chrome и Яндекс.Браузере на разрешениях 1280×720 и 1920×1080, эмулятор Android Studio (Samsung Galaxy S8, Android 9.0).
